# Governance

AKBP is currently maintained by the repository owner.

The project goal is to become a small, practical, implementation-neutral protocol for durable agent knowledge.

## Decision priorities

Protocol decisions should optimize for:

1. portability across agents and tools
2. local-first operation
3. human-readable artifacts
4. machine-readable schemas
5. evidence and citation preservation
6. safe handling of private data
7. testable conformance
8. simple adoption path

## Change process

Small fixes can be made directly through pull requests.

Larger protocol changes should use proposals in `proposals/` and include:

- problem statement
- proposed design
- compatibility impact
- security/privacy impact
- reference implementation notes
- required conformance tests

## Stability

AKBP is pre-1.0. Breaking changes are allowed, but they should be explicit and reflected in dated spec folders.

Stable releases should include:

- dated specification
- schemas
- examples
- conformance tests
- changelog entry
